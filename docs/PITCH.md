# TradeGrid Pitch (1-pager)

Problem: Fragmented liquidity and slow on-chain matching.

Solution: Hybrid CLOB with off-chain matching + on-chain settlement on Aptos (parallel execution).

Differentiation: SDK-first, copy-trading vaults, cross-chain settlement roadmap.

Demo: Place orders -> match -> WS trades -> (optional) on-chain settle.

Roadmap: Rust engine, batch settle, CCTP integration, social features.
